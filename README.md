# Pokédex

Application web Angular 18 connectée à la [PokéAPI](https://pokeapi.co) 

---

## Lancer le projet

```bash
npm install
ng serve
```

Accès : `http://localhost:4200`

---

## Stack technique

| Technologie 
|---
| Angular 
| TypeScript 
| TailwindCSS  
| RxJS 
| PokéAPI 

---

## Pourquoi ces choix

**Angular 18** — J'ai choisi Angular pour son architecture structurée (modules, services, guards, interceptors). Ça m'a permis de séparer clairement les responsabilités et de garder un code lisible.

**TailwindCSS** — J'ai utilisé Tailwind pour éviter de gérer des fichiers SCSS séparés par composant.

**LocalStorage** — J'ai géré les favoris et le thème dark/light avec le LocalStorage, sans backend.
